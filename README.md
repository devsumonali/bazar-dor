# 🛒 Bazar Dor (বাজার দর)

A responsive grocery price tracking web application for Bangladesh. Users can check daily prices, compare market rates, and track price changes.

## 🚀 Features

- View daily grocery prices and price changes
- Browse products by category
- Sort products by price
- Protected product details with market comparisons
- Email/password and social authentication
- Update user profile information
- Responsive design with loading skeletons and toast notifications

## 🛠️ Technologies

Next.js, React, TypeScript, Tailwind CSS, BetterAuth, MongoDB, React Hot Toast, React Icons.

## ⚙️ Installation

```bash
npm install
npm run dev
```

Configure the required environment variables in `.env.local` before running.
